# Nimbus3D — 3D-печать

- Студия 3D-печати, базируется в Дублине (Ирландия), доставка по ЕС.
- Формат продаж: каталог готовых изделий + кастомные заказы по запросу
  (своя модель/фото), без онлайн-оплаты — заявки обрабатываются вручную.
- Категории каталога: фигурки (FIGURINES), декор для дома (HOME_DECOR),
  функциональные предметы (FUNCTIONAL), настольные игры/миниатюры
  (TABLETOP_GAMING), аксессуары для техники (TECH_ACCESSORIES).
- Примеры товаров: подвижная фигурка дракона, лоу-поли лиса, кашпо-соты,
  фотолампа-литофан, мини-вазы, держатель для телефона, органайзер для
  кабелей, модульный органайзер для стола, шахматы геометрической формы,
  набор миниатюр для D&D, фиджет-робот, подставка для запястья.
- Материалы: PLA, PLA+, PETG, TPU, резина (Resin), силиконовый PLA.
- Ценовой ориентир: €12–35 — малые/функциональные изделия, €20–70 —
  средние, €45+ — крупные/многосоставные.
- Ниша: персонализированные подарки (литофаны под фото), товары для
  настольных игр/коллекционеров, аксессуары для рабочего стола, декор.
