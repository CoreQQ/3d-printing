# Promo Agents Bot

Приватный Telegram-бот с тремя AI-агентами (на Claude) для продвижения
двух направлений: **bmwcoding** и **Nimbus3D (3D-печать)**. Доступен
только тебе — все остальные получают отказ.

## Агенты

- **/strategist** — маркетинговая стратегия, позиционирование, цены, каналы, конкуренты
- **/seo** — ключевые слова, тексты объявлений, контекстная реклама, оптимизация площадок
- **/content** — готовые посты, описания товаров/услуг, тексты для соцсетей

Каждый агент видит бизнес-контекст из `src/context/bmwcoding.md` и
`src/context/3d-printing.md`. **Обязательно заполни `bmwcoding.md`** —
сейчас там просто шаблон с подсказками, без него агенты не смогут давать
конкретные советы по этому направлению. Файл про 3D-печать уже частично
заполнен данными из каталога Nimbus3D — дополни его актуальной
информацией (каналы продаж, конкуренты, что уже пробовали).

## Настройка

### 1. Создать бота в Telegram

1. Открой [@BotFather](https://t.me/BotFather) в Telegram.
2. `/newbot` → дай имя и username (должен заканчиваться на `bot`).
3. BotFather выдаст токен вида `123456:ABC-...` — это `TELEGRAM_BOT_TOKEN`.

### 2. Сделать бота приватным

Бот и так не отвечает никому, кто не в списке `ALLOWED_USER_IDS` /
`ALLOWED_CHAT_IDS` — это основная защита. Дополнительно у BotFather можно
выключить добавление бота в чужие группы: `/setjoingroups` → `Disable`.

### 3. Узнать свой Telegram ID

1. Заполни `.env` (см. `.env.example`) без `ALLOWED_USER_IDS`.
2. Запусти бота (см. ниже) и напиши ему `/whoami` в личке — он пришлёт твой `user_id`.
3. Если хочешь общаться в приватной группе — создай группу, добавь туда
   бота, напиши `/whoami` в группе, возьми `chat_id` (он будет отрицательным).
4. Пропиши полученные ID в `ALLOWED_USER_IDS` и/или `ALLOWED_CHAT_IDS` в `.env`.
5. Перезапусти бота.

### 4. API-ключ Claude

Возьми ключ в [console.anthropic.com](https://console.anthropic.com) и
впиши в `ANTHROPIC_API_KEY`.

### 5. Запуск

```bash
cd telegram-bot
cp .env.example .env   # заполни токены и ID
npm install
npm run dev            # для разработки (автоперезапуск)
# или
npm run build && npm run start   # production
```

Бот работает через long polling — это обычный Node-процесс, который
должен быть постоянно запущен (в отличие от frontend/backend этого репо,
которые задеплоены на Vercel как серверless-функции). Подходит:
- VPS / любая машина, где можно держать `npm run start` под `pm2`/`systemd`/Docker;
- Railway, Fly.io, Render (background worker) — любой хостинг для
  long-running процессов, не serverless.

## Использование

- Напиши что угодно в личку (или в приватную группу) — ответит текущий
  агент.
- `/strategist`, `/seo`, `/content` — переключиться на агента.
- `/reset` — очистить историю диалога текущего агента в этом чате.
- `/help` — список команд.

История диалога хранится в памяти процесса (сбрасывается при перезапуске
бота) — для приватного личного использования это осознанный выбор
простоты, не БД.
